# 盲区交火 · 3D战术对战 v0.9

竖屏3D战术游戏，2km × 2km 战场。每一次攻击，也是一条情报。Three.js、车辆GLB、地形、字体和音效随包提供，单人训练无需外部服务。

## 原有功能

- 商城新增 **长鼻熊自行火炮，5000战币**；购买后进入仓库，可设为出战车辆。150HP、27m/s、倒车12m/s、侦察250m。携带152mm火炮、无人机和高射机枪，后二者与悍驴完全共用数值。
- 152mm火炮1.2km射程、5秒装填及曲射/平射，落地爆炸；20m球形爆炸范围，最大95伤害，向边缘线性递减。曲射可点击“地图瞄准”进入俯视全战场，点击35–1200m内位置求解高抛弹道。显示已有侦察目标，不显示未知敌人，保留红色落点箭头。
- 上传的2S19 GLB保留原贴图。真实负重轮、主动轮等连通部件分离后按路程滚动，履带沿闭合履带路线循环，炮塔随瞄准方向转动、炮管随火炮俯仰。悍驴真实导弹发射装置也随瞄准航向转动。
- 敌车从车辆池等概率随机匹配；长鼻熊使用同样的侦察与情报规则，配置火炮进攻、无人机搜索、机枪防御。困难AI原有瞄准误差和反应延迟保留。
- 已侦察敌方车辆/空中单位显示红点；视野外显示屏幕边缘方向提示，沿用最后位置5秒保留。距离较远但肉眼可见的飞行器只绘制模型与轨迹，不显示确认红点或小地图坐标。
- 800棵树的渲染与物理共用确定性坐标；树干阻挡车辆，树干与树冠阻挡弹射物。使用连续线段与圆柱/圆锥碰撞，防止快速飞行器穿过树木；弹道预览也考虑树木。
- 主界面新增实战新手引导，首次启动强制进入。双悍驴教学依次完成介绍、移动、450m外无人机/白尾迹/黄色可疑区域、手操侦察、盘旋、导弹命中、敌方侦察、自动防空、机枪击落和自由击毁。介绍卡等待确认，动作关卡以实际移动/侦察/命中/拦截事件推进；敌人不启用普通AI反击，只在教学指定阶段生成空中威胁。首次完成100战币，重复教学不再奖励。
- 战币/车辆/教程完成状态保存在本机；普通战斗胜100、平50、败25。退出不结算；购买和重复领奖有保护。初始悍驴免费，战币0。
- 远程联机仍关闭，同网版本升级为BLINDFIRE9/状态9，拒绝旧物理客户端。本次源码更新不构建APK，并保留TapTap H5打包流程；网页未部署。

## 操作与规则

左摇杆驾驶或操纵飞行器，拖动画面瞄准；底部选装备，右侧开火。车辆停车后才能发射。无人机、巡航导弹发射后进入手动追尾视角；可返回车辆，接管无人机或切换半径50m盘旋。悍驴不携带火炮；长鼻熊搭载152mm火炮，曲射可切换地图瞄准，曲射/平射均落地爆炸，白色尾迹保留8秒。防空导弹发射后自动追踪；高射机枪按住持续射击。没有诱饵。

双方100 HP，限时3分钟，超时比较剩余耐久。困难AI使用实际侦察、已观察的位置与尾迹线索，不读取未知敌方位置；血量、伤害、装填和侦察规则与玩家相同。

| 装备 | 伤害与行为 | 装填 |
|---|---|---|
| 无人机 | 40秒能量，手动/50m盘旋，贴近自爆30，侦察400m | 10秒 |
| 巡航导弹 | 手动飞行，直击80，近炸45–60，侦察200m | 22秒 |
| 152mm火炮（长鼻熊） | 曲射/平射/地图瞄准，1km，中心86，爆炸半径20m，不可拦截 | 5秒 |
| 防空导弹 | 自动锁定300m内空中目标，优先巡航导弹 | 25秒 |
| 高射机枪 | 手动瞄准，每发空中伤害9 | 无冷却 |

APK：双人交火→同网创建/加入，使用IPv4地址与6位数字码。双方须使用相同的最新源码版本，协议 `BLINDFIRE9` / 状态版本9拒绝旧客户端。主机计算规则，客机只接收过滤后的己方视角；未知敌方位置不传给对手。

## 构建与验证

Android API23起，编译/目标API35，Java8，需要支持WebGL2的较新Android System WebView。JDK17、Gradle8.9、Android SDK35可运行 `gradle assembleDebug`；也可运行 `scripts/build_apk.py --help` 指定SDK、AAPT2、D8/R8、ECJ和签名。交付APK沿用旧版独立签名，可覆盖安装；GitHub Actions调试签名不同。

```sh
python3 scripts/build_h5.py --output build/blindfire-v0.9-taptap-h5.zip
```

H5 ZIP在TapTap后台选择 **H5小游戏** 上传，版本填写 **0.9.0**（若已有更高线上版本，填写更高且唯一的版本号）。按后台上传要求，解压后必须只有一个文件夹，该文件夹下包含 `index.html`；构建脚本已生成这一层目录，直接上传输出ZIP即可。这是后续打包命令。本次未重新构建或上传包；上传后须用平台扫码预览核对真机运行。

- `node tests/garage.test.cjs`、`node tests/artillery-expansion.test.cjs`：初始车辆武器限制、AI装备限制、轮子行驶距离、战币持久化/防重复/异常存储、机枪反应与拦截。
- `tests/garage-browser.test.cjs`：真实WebGL、四个带原贴图的轮子、商城和仓库数值、四种屏幕尺寸、武器入口/键盘、暂停、结算与重新载入存档。
- `node tests/engine.test.js`：33项规则检查，包括300/400/200m边界、多个传感器共享情报、5秒保留、无引信碰撞爆炸及困难AI信息边界。
- `tests/browser.test.cjs`：WebGL、触屏、红色落点箭头、移除提示框、远程入口关闭、四种屏幕尺寸。
- `tests/h5-package.test.cjs`：检查ZIP根目录只有一个文件夹且包含入口，解压真实交付ZIP，使用嵌套托管路径，验证本地模块/字体/GLB/音效、困难训练、火炮、侦察圈、盘旋、暂停及零外部网络请求。
- `tests/multiplayer.test.cjs`、`tests/LanLinkTest.java`：同网双端同步、手动武器与拦截、7版握手、拒绝旧版及断线。
- `tests/web-retirement.test.mjs`：网页及旧资源410、远程默认503且不写数据库，测试环境可显式恢复四位房间服务。
- 原有远程传输测试通过本地显式启用运行，不代表本版开放远程功能。

浏览器检查需要Playwright，可设置 `CHROMIUM_EXECUTABLE`、`SOFTWARE_GL=1`；H5包检查使用 `H5_ZIP` 指定交付ZIP。本地API测试需要Node24。尚未做两台安卓真机同网联测或TapTap客户端扫码验证。

车辆模型由用户提供，保留原车体与贴图、两块纯蓝/纯红小标识；Three.js/GLTFLoader/BufferGeometryUtils采用MIT授权，内置裁剪Noto Sans SC字体，许可证随APK与H5包提供。
