# 盲区交火 · 3D 手动对战 v0.2

竖屏 Android 战术对战。**每一次攻击，也是一条情报。**

3D 丘陵、道路和村镇战场。默认是导弹车第三人称追尾视角，驾驶和五种武器均由玩家手动操作。支持离线 AI 训练、同一 Wi-Fi / 手机热点上的两台安卓设备实时对战。无需账号或下载资源。

## 操作

- 左摇杆：地面前进 / 倒车 / 转向；飞行时上推抬头、下推俯冲、左右转向。
- 拖动画面：调整武器方位、仰角，或飞行器航向。
- 底部选择装备，右侧按钮发射。车辆必须停车才能发射。
- 无人机、巡航导弹、防空导弹发射后立即进入对应飞行器的追尾视角。
- “返回车辆”切回第三人称；飞行器沿最后航向继续飞行，没有自动追踪。可通过“接管无人机”重新控制现有飞机。
- 巡航导弹与无人机可手动引爆，或直接俯冲撞击。
- 机枪需要拖动瞄准并按住开火，松手即停。没有自动选敌、自动瞄准或自动防空。
- 键盘预览：WASD / 方向键驾驶或飞行，1–5 选择装备，空格开火，F 返回车辆，Esc 作战菜单。

| 装备 | 手动行为 | 伤害 / 拦截规则 | 冷却 |
|---|---|---|---|
| 无人机 | 起飞后手动飞行侦察；续航40秒，同时一架 | 无遮挡的215米内确认热源；贴近自爆30；耐久27 | 10秒 |
| 巡航导弹 | 手动转向、俯仰，无自动追踪 | 直击80，近炸45–60；耐久18 | 22秒 |
| 曲射火炮 | 手动调整炮口，显示3D抛物线、预计落点和弹道剖面 | 直击40，范围10–20；炮弹无法转向或拦截 | 5秒 |
| 防空导弹 | 手动瞄准发射并操纵飞行 | 飞到敌方无人机 / 导弹12米内，由近距引信引爆；不自动寻的 | 18秒 |
| 高射机枪 | 沿手动炮口方向连续射击 | 每发空中伤害9；需要实际命中 | 无冷却 |

炮弹、导弹、无人机和防空弹在天空留下白色轨迹，每一段保留8秒，命中或击落后仍会按剩余时间保留。火炮预览和实际炮弹共用初速、重力和地形碰撞；建筑也参与碰撞。车辆不能穿过建筑或战区边界。

诱饵已移除。

## 情报与胜负

双方开局只知道自己的位置。发射车近距离目视和无人机侦察可以确认敌方；地形和建筑阻挡视线。脱离侦察后5秒失去精确情报，再保留旧位置至22秒。击落无人机会给失去飞机的一方留下防空疑似区域。

小雷达只显示己方和已经获得的情报。敌方发射原点、真实隐藏位置、目标、装备冷却和操纵状态不会进入对手客户端；可见飞行器和尾迹会提供反推方向的线索。AI 使用自己的目视、无人机和尾迹情报决策。

100 HP，限时3分钟。摧毁对方获胜；超时比较剩余耐久，相同则平局。

## 双人模式

A创建房间，B输入A显示的IPv4地址与6位房间码。两台手机须安装同一版本，并连接同一 Wi-Fi 或手机热点。公共网络的设备隔离可能阻止连接。切至后台或断开连接会终止双人对局；双人作战菜单不暂停对方。

A端是规则主机，B端传输手动操作并接收自己的视角。输入校验、冷却、禁射、伤害、拦截、倒计时和胜负均由主机计算。连续输入有超时保护；传输含序号、频率限制与心跳。v0.2 使用 `BLINDFIRE2` 握手，拒绝旧版客户端。

## 构建

- Android API 23起，编译 / 目标 API 35，竖屏，Java 8。
- 原生 WebView 外壳 + 本地 Three.js r166 / WebGL 2，所有美术由程序生成。
- 手机需支持 WebGL 2，使用较新的 Android System WebView / Chrome。
- JDK 17 + Gradle 8.9 + Android SDK 35：`gradle assembleDebug`。
- GitHub Actions 自动运行规则与TCP检查，生成 debug APK。
- 无 Gradle 时可用 `scripts/build_apk.py --help`，指定 Android SDK android.jar、AAPT2、D8/R8、签名和 zipalign。

交付 APK 沿用 v0.1 的独立开发签名，可以覆盖安装。签名材料不在公开仓库。Actions 的 debug APK 使用默认调试签名，不能覆盖独立签名包。

## 验证

- `node tests/engine.test.js`：14项规则检查，包含3D驾驶、真实抛物线与落点、8秒尾迹、手动飞行、侦察过期、伤害、SAM / 机枪命中与偏离、炮弹不可拦截、AI和网络情报边界、整局结束。
- `tests/browser.test.cjs`：Playwright真实WebGL画面、触屏驾驶 / 瞄准、五种武器、追尾切换、暂停 / 重开、4种屏幕尺寸。
- `tests/multiplayer.test.cjs`：两个3D客户端建立房间，B手动驾驶与开火，防空和导弹追尾视角、冷却 / 伤害同步、断线处理。
- `tests/LanLinkTest.java`：真实TCP传输、房间码校验、版本拒绝、双向UTF-8与断线。

浏览器检查可使用 `CHROMIUM_EXECUTABLE` 指定 Chromium，`SOFTWARE_GL=1` 启用软件渲染。已做规则、触屏、双客户端和本机TCP验证，尚未做两台安卓真机联测。暂不支持互联网匹配。
