# 盲区交火 · 第一版 v0.1

竖屏 Android 战术交火小游戏。**每一次攻击，也是一条情报。**

开局只看得到自己的发射车。通过无人机、可见弹道和防空交火搜索对方，确认热源后打击，再转移以躲避反击。

## 已实现

- 离线玩家对 AI，提供新兵、标准两种难度。AI 依据自己的侦察与弹道情报选择目标。
- 同一 Wi-Fi 或手机热点上的两台安卓设备实时对战，无需账号。
- 随机出生、8×12 方位参考、自由点击侦察/攻击与实际飞行。
- 未知、方向线索、疑似区域、精确定位与过期位置。
- 100 HP，3 分钟限时；摧毁对方获胜，超时比较耐久，相同为平局。
- 移动、热源诱饵、命中反馈、声音/震动、暂停与战后结算。

| 装备 | 规则 | 冷却 |
|---|---|---|
| 无人机 | 从车旁起飞，指定地点盘旋20秒，侦察半径150，最多两架；可被击落 | 10秒 |
| 无人机俯冲 | 指挥已有无人机飞向指定攻击点，命中30伤害 | 使用已有无人机 |
| 巡航导弹 | 直击80，近炸45–60；可被防空拦截，轨迹生成方向线索 | 22秒 |
| 曲射火炮 | 直击40，范围10–20；飞行快，不能被防空拦截 | 5秒 |
| 防空导弹 | 300范围自动选择空中目标，优先导弹，92%拦截成功率 | 18秒 |
| 高射机枪 | 按住连续射击，140范围内自动瞄准无人机/导弹 | 无冷却 |
| 机动 | 最远210，速度48/秒；移动时停止发射 | 6秒 |
| 热源诱饵 | 在当前位置留下持续24秒的假热源，再机动离开 | 20秒 |

无人机视野内持续刷新精确位置；失去扫描后5秒转为旧位置，22秒后消失。击落无人机产生以损失点为中心的防空疑似区域，不直接给出对方坐标。诱饵在侦察中同样表现为热源。

## 操作

选择无人机/导弹/火炮后点击地图；选择机动或无人机俯冲后点击目的地。诱饵与防空导弹直接点按钮，高射机枪按住射击。

双人模式：A创建房间，B输入A显示的地址与6位房间码。两台设备需要安装相同版本并连接同一 Wi-Fi 或热点；部分公共网络的设备隔离会阻止连接。切至后台或断线会终止双人对局。双人菜单不暂停另一位玩家。

## 构建

- Android 6.0 / API 23 起，编译/目标 API 35，竖屏，Java 8。
- 原生 WebView 外壳 + 本地 Canvas 游戏；无需联网下载美术或代码，单人完全离线。
- 使用较新的 Android System WebView。源码无第三方游戏引擎依赖。
- JDK 17 + Gradle 8.9 + Android SDK 35：`gradle assembleDebug`。
- GitHub Actions 自动检查规则并生成 debug APK。
- 无 Gradle 时可使用 `scripts/build_apk.py --help`，需指定 SDK android.jar、AAPT2、D8/R8、签名与 zipalign 工具。

交付 APK 使用独立开发签名。签名材料不放在公开仓库；后续覆盖安装需要沿用交付签名。Actions 的 debug APK 使用其默认调试签名，不能直接覆盖独立签名包。

## 验证

`node tests/engine.test.js` 检查出生、冷却、移动禁射、侦察、情报过期、伤害、拦截、诱饵与 AI 信息边界。

`tests/LanLinkTest.java` 检查真实 TCP 连接、错误房间码拒绝、双向 UTF-8 数据与断开通知。

`tests/browser.test.cjs` 与 `tests/multiplayer.test.cjs` 使用 Playwright 检查触屏界面、多尺寸布局及两个浏览器客户端的完整对局同步。可用环境变量 `CHROMIUM_EXECUTABLE` 指定浏览器。

双人模式由A端模拟规则，仅将B的视角传给B。隐藏的敌方位置、发射原点、目的地、路线与冷却不会进入客户端视图；按钮指令在A端校验坐标、冷却、移动限制和序号。

首版地形用于辨认方位，暂不限制车辆穿越；支持同网双人，尚未加入互联网匹配。已做规则、界面和传输检查，未做两台安卓真机联测。

UI字体是按界面文字裁剪的 Noto Sans SC，许可证见 `app/src/main/assets/font-LICENSE.txt`。
