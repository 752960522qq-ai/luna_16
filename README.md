# 盲区交火 · 3D远程对战 v0.5

竖屏 Android 3D 战术对战。**每一次攻击，也是一条情报。**

2km × 2km 的丘陵、道路和村镇战场。默认是导弹车第三人称追尾视角。支持离线 AI 训练，以及同一 Wi-Fi / 手机热点上的两台安卓设备实时对战。所有代码和美术资源随 APK 提供，单人完全离线。

## v0.5 远程联机与网页版

- 公开网页版：[盲区交火](https://blindfire-arena.expert-eagle-6942.chatgpt.site)。支持键盘、鼠标和触屏操作。
- 双人交火菜单可以创建远程房间或输入8位房间码加入。安卓APK与网页版共用房间，双方无需处于同一网络，也无需账号。原来的6位房间码 / IPv4同网模式保留在APK中。
- 远程HTTPS中继负责保存客机视角与有序操作；玩家A继续计算物理、侦察和伤害。房间成员使用各自的随机连接凭据。命令序号、主机确认与重试去重防止重复发射，服务不把未发现的敌人坐标发给客机。
- 显示往返延迟；断网超时、退出或切至后台会终止连接，重新建房即可再战。远程服务需要网络，APK单人训练保持完全离线。对战可能受跨地区网络延迟影响。
- `web/` 包含完整远程房间服务、D1迁移与公开游戏构建脚本。每局的状态是临时数据，没有账号、排行榜或互联网自动匹配。

## v0.4 更新

- 使用提供的 M1097 Avenger 车辆模型，保留车体、玻璃与原贴图。移除多余的蓝白 / 红白标识和信标；车体左右两侧各留一块较小的纯蓝 / 纯红标识。
- 火炮增加 **曲射 / 平射** 切换。曲射初速240m/s、仰角34–77°，平地最远约1.7km；平射初速310m/s、俯仰角−13–17°。两种模式显示各自的3D抛物线、预计落点和剖面，共用5秒装填。切换不会重置装填。
- 无人机可切到 **半径50m自动盘旋**，同时返回车辆操作其他装备。再次点击切回手动追尾飞行。盘旋继续提供300m侦察、仍能被拦截，使用起飞后的原40秒续航，切换不补充能量。边界附近会将盘旋圆心移入战区，并平滑飞入圆周；盘旋高度避开地面与建筑。
- 增加离线合成的无人机起飞、巡航 / 防空导弹发射、火炮、连续机枪、命中和爆炸音效。发动机声音随车速变化；飞离车辆后逐渐减弱。武器声音由主机确认，重复快照不重复播放；支持静音、暂停、后台释放。
- 保留v0.3.1的多指触控、后台连接与过期回调修复。联机协议更新为 `BLINDFIRE4`，双人对战两端均须更新到v0.4。沿用原签名，可覆盖安装。

## 战斗规则

- 战区坐标为 `0–2000m × 0–2000m`。出生、驾驶边界、弹道、碰撞、AI 搜索、地形和小地图使用同一尺寸。
- **导弹车、巡航导弹、无人机统一提供半径300m的共享侦察。** 无论是否正在操纵飞行器，都能侦察。按空间距离触发，无需手动锁定或朝向；建筑和丘陵参与物理碰撞，侦察按范围判定。
- 范围内持续刷新敌方车辆与空中单位。脱离所有我方侦察范围后，3D画面和小地图显示最后发现的位置 **5秒**，随后同时移除。重新进入任意侦察范围会刷新计时。取消旧版额外22秒的过期位置显示。
- 小地图覆盖整个2km战场。绿色圆圈表示我方侦察范围；橙色表示当前敌情，褐色表示保留中的情报。远处的巡航导弹或无人机发现敌人时也能在全图显示。
- **防空导弹发射后自动锁定、预测并追踪空中目标，装填25秒。** 优先巡航导弹，其次无人机 / 防空导弹。无需手动瞄准或操纵，保持车辆视角；目标丢失可在自身300m内重新搜索。发射时300m内没有空中目标则提示，并且不消耗装填。炮弹不是可拦截目标。
- 巡航导弹、无人机、火炮和机枪继续手动操作。白色轨迹的每一段保留8秒。没有诱饵。

## 操作与武器

左摇杆驾驶或操纵飞行器，拖动画面瞄准，底部选择装备，右侧按钮开火。车辆停车后才能发射。无人机和巡航导弹发射后切换追尾视角；摇杆上推抬头、下推俯冲、左右转向。可返回车辆，再次接管无人机；未启用盘旋的无人机和未被操纵的巡航导弹沿最后航向继续飞行。火炮弹道面板内切换曲射 / 平射；无人机飞行时或返回车辆后可点击50m盘旋 / 手动飞行。

| 装备 | 行为 | 伤害 / 拦截 | 装填 |
|---|---|---|---|
| 无人机 | 手动 / 50m盘旋、300m共享侦察；总续航40秒，同时一架 | 贴近自爆30，耐久27 | 10秒 |
| 巡航导弹 | 手动飞行、300m共享侦察，无自动寻的 | 直击80，近炸45–60，耐久18 | 22秒 |
| 火炮 | 曲射 / 平射手动瞄准，3D抛物线与落点；曲射约1.7km | 直击40，范围10–20，无法转向或拦截 | 5秒 |
| 防空导弹 | 自动锁定并追踪，保持车辆视角 | 飞到空中目标12m内由近距引信完成拦截 | 25秒 |
| 高射机枪 | 手动瞄准，按住连续射击，松手即停 | 每发空中伤害9，需要实际命中 | 无冷却 |

火炮预览与实际炮弹共用初速、重力和地形碰撞。车辆不能穿过建筑或战区边界。100 HP，限时3分钟；摧毁对方获胜，超时比较剩余耐久，相同为平局。

键盘预览：WASD / 方向键驾驶或飞行，1–5选择装备，空格开火，F返回车辆，Esc作战菜单。

## 双人模式与信息边界

A创建房间，B输入A显示的IPv4地址与6位房间码。同网模式的两台手机须安装兼容版本并连接同一网络；公共网络设备隔离可能阻止连接。切至后台或断线会终止双人对局，双人作战菜单不暂停对方。

A端计算规则，B端传输操作并接收自己的视角。输入校验、装填、伤害、自动防空、侦察和5秒情报过期、火炮模式和无人机盘旋均由主机计算。传输含序号、频率限制、超时保护和心跳。v0.4使用 `BLINDFIRE4` 握手，拒绝旧版客户端。

未发现的敌方车辆位置、发射原点、目标ID、冷却和操纵状态不会进入对手客户端。脱离侦察后不再更新保留目标的真实位置。可见白色尾迹和爆炸仍可提供方向线索。AI与玩家使用同样的侦察和自动防空规则。

## 构建

- Android API23起，编译 / 目标 API35，竖屏，Java8。
- 原生 WebView 外壳 + 本地 Three.js r166 / GLTFLoader / WebGL2，内置GLB车辆，程序生成地形、飞行器和音效。
- 手机需支持 WebGL2，使用较新的 Android System WebView / Chrome。
- JDK17 + Gradle8.9 + Android SDK35：`gradle assembleDebug`。
- GitHub Actions检查规则和真实TCP，生成debug APK。
- 无Gradle可使用 `scripts/build_apk.py --help`，指定 Android SDK android.jar、AAPT2、D8/R8、签名和zipalign。

交付APK沿用v0.1 / v0.2的独立开发签名，可以覆盖安装。签名材料不在公开仓库。Actions默认调试签名不能覆盖独立签名包。

可用 `CHROMIUM_EXECUTABLE` 指定Chromium，`SOFTWARE_GL=1` 启用软件渲染。已做规则、界面、双客户端及本机TCP检查，尚未做两台安卓真机联测。远程使用房间码邀请对战，尚未做两台安卓真机跨网络联测。

字体是裁剪的 Noto Sans SC，见 `app/src/main/assets/font-LICENSE.txt`。Three.js 使用MIT许可证，见 `app/src/main/assets/three-LICENSE.txt`。

提供的车辆模型由用户提供，车体几何与贴图未重制；`scripts/clean_vehicle.py` 可重现标识清理。GLTFLoader与BufferGeometryUtils同属Three.js MIT授权，均随包本地加载。

远程服务的本地验证需要Node24（`node:sqlite`）；网页构建使用预先生成的Drizzle迁移，`npm ci && npm run db:generate` 可在新的发布前生成迁移。网站源码由公开游戏资源与 `web/` 组成，Sites托管版本和GitHub仓库保留相同游戏内容。

网页复现：在 `web` 目录将 `../app/src/main/assets` 复制为 `public`，将 `hosting.json` 复制到 `.openai/hosting.json`，再运行 `npm ci && npm run build`。`public` 内容全部来自安卓包的同一游戏代码。
