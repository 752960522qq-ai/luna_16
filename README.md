# 盲区交火 · 3D战术对战 v0.7

竖屏3D战术游戏，2km × 2km 战场。每一次攻击，也是一条情报。Three.js、车辆GLB、地形、字体和音效随包提供，单人训练无需外部服务。

## 本版修改

- **暂时关闭远程联机。** APK 不初始化远程 HTTP 客户端，远程入口移除；JS 与原生桥接均拒绝远程调用。公开后台默认返回503“远程联机暂时关闭”，只有显式设置 `ROOMS_ENABLED=true` 才会恢复房间服务。原网页游戏仍关闭，游戏资源不对外提供。APK保留同一Wi-Fi或热点下的同网对战。
- **火炮落点改为悬浮红色箭头。** 删除屏幕落点提示框，箭头指向真实抛物线的着地点，轻微上下浮动，随镜头朝向保持可辨认；保留抛物线预览、曲射/平射切换、约1km射程和小地图标记。战区外没有虚构落点。
- **各单位独立侦察范围。** 车辆300m、无人机400m、巡航导弹200m，按3D距离判断，对双方及AI一致。返回车辆、接管或盘旋不影响飞行器侦察。目标离开全部有效侦察范围后，3D画面和小地图保留最后已知位置5秒。小地图侦察圈与对应单位范围一致。防空导弹锁定范围仍300m、装填25秒。
- **同时交付APK与TapTap H5 ZIP。** H5包根目录为 `index.html`，资源全部随包提供，可部署在子目录；H5隐藏同网对战入口，提供新兵、标准、困难三种训练难度，不调用ChatGPT联机服务。

v0.6 的工作环境联测请求经过带ChatGPT签名的出口，不能代表普通手机网络可通过托管入口。实际用户遇到非JSON的403，具体入口规则尚未取得。因此本版暂停远程功能，不再把旧联测结果作为手机端修复证明。

## 操作与规则

左摇杆驾驶或操纵飞行器，拖动画面瞄准；底部选装备，右侧开火。车辆停车后才能发射。无人机、巡航导弹发射后进入手动追尾视角；可返回车辆，接管无人机或切换半径50m盘旋。火炮面板切换曲射/平射，炮弹无定时引信，撞地面、建筑或车辆才爆炸，8秒白色尾迹保留。防空导弹发射后自动追踪；高射机枪按住持续射击。没有诱饵。

双方100 HP，限时3分钟，超时比较剩余耐久。困难AI使用实际侦察、已观察的位置与尾迹线索，不读取未知敌方位置；血量、伤害、装填和侦察规则与玩家相同。

| 装备 | 伤害与行为 | 装填 |
|---|---|---|
| 无人机 | 40秒能量，手动/50m盘旋，贴近自爆30，侦察400m | 10秒 |
| 巡航导弹 | 手动飞行，直击80，近炸45–60，侦察200m | 22秒 |
| 火炮 | 曲射/平射，约1km，直击40，范围10–20，不可拦截 | 5秒 |
| 防空导弹 | 自动锁定300m内空中目标，优先巡航导弹 | 25秒 |
| 高射机枪 | 手动瞄准，每发空中伤害9 | 无冷却 |

APK：双人交火→同网创建/加入，使用IPv4地址与6位数字码。双方须使用v0.7，协议 `BLINDFIRE6` / 状态版本6拒绝旧客户端。主机计算规则，客机只接收过滤后的己方视角；未知敌方位置不传给对手。

## 构建与验证

Android API23起，编译/目标API35，Java8，需要支持WebGL2的较新Android System WebView。JDK17、Gradle8.9、Android SDK35可运行 `gradle assembleDebug`；也可运行 `scripts/build_apk.py --help` 指定SDK、AAPT2、D8/R8、ECJ和签名。交付APK沿用旧版独立签名，可覆盖安装；GitHub Actions调试签名不同。

```sh
python3 scripts/build_h5.py --output build/blindfire-v0.7-taptap-h5.zip
```

H5 ZIP在TapTap后台选择 **H5小游戏** 上传，版本填写 **0.7.0**（若已有更高线上版本，填写更高且唯一的版本号）。无需把ZIP当APK上传或再次套一层目录。上传后用平台扫码预览核对真机运行；本项目完成的是H5包构建及浏览器验证，尚未提交到用户TapTap账号。

- `node tests/engine.test.js`：33项规则检查，包括300/400/200m边界、多个传感器共享情报、5秒保留、无引信碰撞爆炸及困难AI信息边界。
- `tests/browser.test.cjs`：WebGL、触屏、红色落点箭头、移除提示框、远程入口关闭、四种屏幕尺寸。
- `tests/h5-package.test.cjs`：解压真实交付ZIP，使用嵌套托管路径，验证本地模块/字体/GLB/音效、困难训练、火炮、侦察圈、盘旋、暂停及零外部网络请求。
- `tests/multiplayer.test.cjs`、`tests/LanLinkTest.java`：同网双端同步、手动武器与拦截、6版握手、拒绝旧版及断线。
- `tests/web-retirement.test.mjs`：网页及旧资源410、远程默认503且不写数据库，测试环境可显式恢复四位房间服务。
- 原有远程传输测试通过本地显式启用运行，不代表本版开放远程功能。

浏览器检查需要Playwright，可设置 `CHROMIUM_EXECUTABLE`、`SOFTWARE_GL=1`；H5包检查使用 `H5_ZIP` 指定交付ZIP。本地API测试需要Node24。尚未做两台安卓真机同网联测或TapTap客户端扫码验证。

车辆模型由用户提供，保留原车体与贴图、两块纯蓝/纯红小标识；Three.js/GLTFLoader/BufferGeometryUtils采用MIT授权，内置裁剪Noto Sans SC字体，许可证随APK与H5包提供。
