# 盲区交火 · 3D战术对战 v0.6

竖屏 Android 游戏，2km × 2km 战场。**每一次攻击，也是一条情报。** 本地 Three.js、车辆GLB、地形和音效随APK提供，单人训练完全离线。

## 本版修改

- **修复远程连接。** 旧版 WebView 的跨域预检被服务入口拦截为403；APK改用原生 HTTPS 客户端，直接提交请求，保留服务Cookies、正常校验证书，并明确显示超时和服务错误。浏览器开发预览使用不需要预检的简单请求。
- **远程房间使用4位数字码。** 例如0428，前导零会保留。创建时检测碰撞；每位玩家仍使用独立48位随机私密凭据授权，房间码不会代替凭据。双方均须更新至v0.6。
- **网页版已关闭。** 后台只提供 `/api/rooms/` 联机接口，其他路径返回410；不再提供网页游戏、脚本、字体或模型。保留后台是为了APK远程对战。
- **火炮最大平地射程约1km。** 曲射初速约184m/s、45–87°；平射310m/s、−13–10°。两种模式共用5秒装填。炮弹无定时引信、无高空超时销毁，撞击地面、建筑或车辆才爆炸；飞出战区的炮弹清理时不会产生爆炸。8秒白色尾迹照常保留。
- **落点更清晰。** 亮黄色3D圆环和十字、小地图落点标记、屏幕距离和预计着地时间；落点在画面外时显示方向箭头，在战区外时明确提示。标记避开火炮模式切换面板。
- **新增困难AI。** 分区侦察并继续未完成的路线，利用实际尾迹线索推断搜索区；无人机靠近已发现目标后50m盘旋，保持侦察；根据已观察的移动估计提前量，使用高弧线火炮、手动制导巡航和发射后转移；防空导弹装填时改用机枪。血量、伤害、冷却、能量和侦察范围与玩家相同，未知敌人不会用于搜索决策。已发射导弹可以继续飞向以前确认的位置，不会跟踪后来未知的移动。

## 操作与规则

左摇杆驾驶或操纵飞行器，拖动画面瞄准；底部选装备，右侧开火。车辆停车后才能发射。无人机、巡航导弹发射后进入手动追尾视角；可返回车辆，接管无人机或切换半径50m盘旋。火炮面板切换曲射/平射，防空导弹发射后自动追踪，高射机枪按住持续射击。没有诱饵。

车辆、无人机、巡航导弹共享300m距离侦察。脱离全部侦察范围后，世界画面和小地图只保留最后已知位置5秒，随后同时隐藏。双方100 HP，限时3分钟，超时比较剩余耐久。

| 装备 | 伤害与行为 | 装填 |
|---|---|---|
| 无人机 | 40秒总能量，手动/50m盘旋，贴近自爆30 | 10秒 |
| 巡航导弹 | 手动飞行，直击80，近炸45–60 | 22秒 |
| 火炮 | 曲射/平射，约1km，直击40，范围10–20，不可拦截 | 5秒 |
| 防空导弹 | 自动锁定300m内空中目标，优先巡航导弹 | 25秒 |
| 高射机枪 | 手动瞄准，每发空中伤害9 | 无冷却 |

双人交火→创建远程房间，把4位码发给对方，另一台APK选择加入远程房间。无需同一Wi-Fi或账号。保留同网模式：使用IPv4地址与6位数字码。对战期间保持应用在前台；退出、切至后台或断线会关闭对局。

主机计算60Hz规则，客机接收自己的过滤视角并发送有序操作。HTTPS中继使用序号、确认和重试去重；未发现的敌方位置、发射原点、冷却与操纵状态不发送给对手。协议更新为 `BLINDFIRE5` / 状态版本5，拒绝旧客户端。

## 构建与验证

Android API23起，编译/目标API35，Java8。需要支持WebGL2的较新Android System WebView。JDK17、Gradle8.9、Android SDK35可运行 `gradle assembleDebug`；也可使用 `scripts/build_apk.py --help` 指定SDK、AAPT2、D8/R8、ECJ和签名。交付包沿用旧版独立开发签名，可覆盖安装；GitHub Actions调试签名不同。

- `node tests/engine.test.js`：32项规则检查，包含无引信落地爆炸、双模式预览匹配、300m/5秒情报、困难AI信息边界、预判、合法防空、盘旋与转移。
- `node tests/remote-server.test.mjs`：HTTP/SQLite房间、抢房、凭据隔离、同步、重复操作确认、过期与关闭。
- 编译 `RemoteHttp.java`、`tests/RemoteHttpTest.java` 后运行 `node tests/native-remote.test.mjs`：两个实际原生网络客户端，无OPTIONS预检，四位码、私密凭据、操作同步、确认与退出。已对公开HTTPS后台实测通过。
- `tests/browser.test.cjs`、`tests/remote-browser.test.cjs`：真实WebGL、触屏、困难入口、落点与小地图标记、四种屏幕尺寸，异步原生桥接及简单CORS远程对战。
- 原有 `tests/multiplayer.test.cjs`、`tests/lifecycle.test.cjs`、`tests/audio.test.cjs`、`tests/LanLinkTest.java`、`tests/models.test.py` 保留。

浏览器检查需要Playwright，可设置 `CHROMIUM_EXECUTABLE` 和 `SOFTWARE_GL=1`。远程本地检查需要Node24。后台复现：在web目录复制hosting.json到.openai/hosting.json，执行 `npm ci && npm run build`。无需复制游戏资源。

已完成公开后台与实际原生网络代码的双端测试，尚未做两台安卓真机跨网络联测。

车辆模型由用户提供，保留原车体与贴图、两块纯蓝/纯红小标识；Three.js/GLTFLoader/BufferGeometryUtils采用MIT授权，内置裁剪的Noto Sans SC字体，许可证随APK提供。
