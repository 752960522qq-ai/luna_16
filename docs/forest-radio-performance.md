# 黑暗森林性能与500米通信

CPU采样定位到车辆碰撞、湖区判断、建筑视线以及情报扫描的重复开销。本次将定向车体碰撞拆成vehicle-collision模块，树木先作包围范围排除，车辆远离湖区时跳过九点湖区检测。AI导航方向仅在100毫秒内、车辆移动不足2米且目标变化不足8米时复用；实际移动碰撞仍逐步检测。建筑视线增加精确包围范围排除。

黑暗森林的自动情报扫描改为约10Hz，移动、炮弹、伤害和缩圈仍沿用原物理步。显式观察和情报扫描立即执行。同一情报扫描内缓存同一观察者对同一目标的检测，扫描结束清空，避免错误沿用位置、乘员或隐蔽状态。没有降低模型精度、侦察半径或弹道精度。

所有车辆新增communicationRange=500米。突破无人区通过独立team-recon模块交换车体及空中目标情报，只允许存活同队车辆之间500米（含边界）直接共享；不将已共享情报再次转发。距离按车体水平坐标计算，两车取较小的通信范围。前哨报告只发给500米内车辆，不通过车辆中继。共享情报不会触发自身发现敌人的语音。

超过通信范围后不刷新目标坐标和时间；已有报告变为最后已知信息，按原来源保留时间过期。重新进入范围后可接收新报告。自身仍能侦察时以自身情报为准。前哨侦察半径仍500米。

提供的图标原图直接替换Android drawable/ic_launcher，保留完整图像；未打包APK。

验证：2万组城墟/丘陵定向碰撞与原实现完全一致；黑暗森林三难度完整回合、引擎33项、隐蔽/语音规则、通信边界/断联/保留/重连/死亡/禁止中继/空中情报通过。软件WebGL验证接地、炮镜、横屏、设置、结构模型和重生界面。CPU优化不等于真机帧率承诺，安卓设备性能仍需实测。
