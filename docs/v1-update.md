# 1.0 源码更新

- 应用版本 1.0，版本码 12；菜单同步显示 v1.0。本次不构建 APK。
- 暂停驾驶员、炮长、二炮手、无线电员的“乘员就位”播报和系统语音准备。保留战斗事件随机语音池；删除两段紧急装填录音、播放池与狂按发射键的触发逻辑，当前保留 60 段无线电处理录音。
- 黑暗森林每个完整毒气暴露秒扣最大耐久的 2%，四舍五入为整数；不会使用当前剩余 HP 计算，也不经过装甲免疫。例如军马每秒 4HP、歼灭者FV每秒 3HP。

## 模型与验证

`scripts/prepare-v1-vehicles.mjs` 校正上传模型到米制、Y向上、车头−Z；保留有效三角面、UV和材质，仅移除未使用数据、压缩贴图与几何。军马原有偏斜坐标先校正，再适配车体与炮管长度。炮口、炮管关节、炮塔中心、轮履接地和FV四个发射口均从生产GLB提取到 `v1-model-data.js`。四个蚂蜂发射位置按模型尾部出筒，固定架不跟随瞄准转动。

实际WebGL验证覆盖两辆车的贴图、尺寸、轮履行驶/转向动画、军马炮塔/俯仰、城市与丘陵接地、炮口及发射口位置。当前实测炮口误差低于0.005米。军马28个真实轮轴（避免将后导轮扇形零件识别成独立轮子）、FV四个完整轮组均验证了转动。仓库使用实际模型渲染缩略图，离线字体包含新载具文字。缩略图需要更新时运行 `UPDATE_V1_THUMBNAILS=1 CHROMIUM_EXECUTABLE=... SOFTWARE_GL=1 node tests/v1-browser.test.cjs`；常规测试不覆盖已提交图片。

新战斗状态使用版本10，同网握手BLINDFIRE10拒绝旧客户端。独立APK脚本现从Gradle读取应用版本，并生成正确的BuildConfig，避免以后产物继续显示旧版本。

验证：`tests/v1-gameplay.test.cjs`、`tests/v1-browser.test.cjs`；现有引擎33项、八级平衡、侦察/语音、黑暗森林完整对局、模型渲染、TCP同网握手和字体检查。没有安卓真机安装验收，也没有生成1.0 APK。
