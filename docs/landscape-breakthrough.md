# 横屏与突破无人区

默认模式为本地玩家加9辆AI的5v5突破无人区，原1v1与黑暗森林仍可选择；同网对战仍是1v1，协议11拒绝旧客户端。

## 战斗规则

每局600秒。双方各一个基地、三个横向ABC前哨；两条前哨战线相距1000米，载具出生点在己方基地前200米。一级前哨700HP、基地1200HP；每升一级分别增加150和300HP，房间等级取出战队列最高等级。前哨提供500米侦察，建筑伤害支持直接命中与范围衰减。

初始出战加三次重生，队列最多四辆不同的已拥有载具；被击毁车辆标记损坏，不能本局再次出战。点击下方缩略图切换主菜单展示，信息按钮查看车辆资料，编辑队列调整出战顺序。

尚未摧毁敌方任一前哨时越过敌方战线，战术装备停用且冷却冻结，主武器可继续使用。摧毁任一敌方前哨后解除限制。摧毁敌基地、耗尽敌方全部载具可提前获胜；时间结束比较基地与前哨剩余总HP，相同则平局。

## 操作与适配

Android锁定横屏；菜单参考机库布局，中央模型、左右信息与战斗入口、底部队列。设置中独立调节游戏、音乐和语音音量，拖动HUD后保存；油门位于轰炸机驾驶界面右侧。菜单音乐使用轻量程序音源。

模型接地测量使用局部矩阵，避免异步加载将世界坐标误当车底尺寸。出生点使用实际朝向检查车体碰撞。坦克炮弹方向、炮镜与炮口共同使用接地后的炮管几何。前哨与基地模型压缩后复用几何与材质，AI绕过城市建筑寻找可射击位置。

角斗士装填9秒；JU87耐久150、炸弹中心160伤害、油门速度30—90m/s；侦察机耐久130。新增三辆车补齐引擎音效配置。
