# 黑暗森林与载具修复

本轮仅提交源码，不运行APK打包。此前未推送的二级载具、科技树与动画优化一并同步。

## 对战

菜单AI对战增加模式选择，默认1v1。黑暗森林为8辆互相敌对的载具（玩家1辆、AI7辆），随机出生在可通行位置，初始间隔至少240m。AI按既有等级匹配池选择车辆。各车独立保留发现目标和5/8秒情报，渲染、地图标记、炮弹碰撞和爆炸伤害支持任意车辆编号。

安全区中心为地图中心，60、120、180、240、300秒半径分别为1000、750、500、250、0m。圈外持续8HP/s，300秒后全图30HP/s，毒气不受坦克装甲免伤保护。AI发现圈外危险后驶向圈内；显示剩余存活数、下一次缩圈时间、小地图安全圈、地面圈线和圈外绿色屏幕边缘。提前只剩1车即可结束；第300秒不按血量直接结算，毒气继续至最后存活者。最终同帧毒气同血量淘汰采用稳定编号打破平局，确保一个胜者。玩家淘汰后停用操作，继续等待结算排名。

## 载具与火炮

B号引擎声采用较低怠速和随车速变化的音高/音量，20mm开炮为专用短音效，10发耗尽时触发换弹机械音。维修/暂停/后台/关闭声音行为保留。坦克搜敌用随机巡逻、发现方向线索、车长观察；B号发现目标后持续逼近至约65m，并在射程和视线允许时开火，不读取未知敌方位置。

跳虫16组原始轮轴重新挂接前刷新父级世界矩阵，防止模型件位置错误。履带各个刚性链节的不同材质部件共享相位，修正履带与负重轮的地面接触移动方向，GPU移动原始几何，不逐帧改写顶点。多辆敌车独立持有炮管、轮组和GPU动画参数。

火炮只保留连续俯仰，地图选点依次尝试高弧和低弧；不可达落点明确提示。跳虫−3°～+72°/900m，长鼻熊−3°～+68°/1300m，按弹速标定平地射程。炮弹预览、实际飞行和AI共用物理参数。长鼻熊原300HP、260中心伤害和强化无人机保留。城市灰色地面、灰墙及深灰屋顶，工厂和商业街区有独立外观与实体碰撞，保留城市湖泊和路网。
