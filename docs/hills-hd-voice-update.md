# 丘陵交火高清化与语音更新

用户提供的 leafy_grass.webp、asphalt_pit_lane.webp、rock_wall_04.webp 分别用于草地、柏油路和房屋墙壁。保持现有地形、道路、村落、天空和屋顶结构。low_poly_tree_scene_free.glb 只提取一棵带树冠的树和一簇草，river_rock.glb 的三块岩石分别提取、归零并独立排布。prepare-hills-assets.py 保留 UV、法线和材质，仅复制所选 accessor 和贴图，模型总计约 3 MB；贴图限制到 1024，使用 WebP。植被和岩石按空间区块实例化，模板共享贴图，地图重建回收私有几何与材质。

房屋沿用模型对应长宽高碰撞箱；树干碰撞半径及偏心位置来自提取模型底部几何，树冠使用模型尺寸包围盒参与弹道/视线遮挡；岩石使用各自的旋转包围盒。草丛为可穿行的隐蔽触发区域，保留原隐蔽参数。全部载具使用配置中的长宽高和碰撞偏移，旋转矩形 SAT 检查相互重叠；车辆每 0.4m 子步检查移动，避免高速越过窄碰撞箱，不增加碰撞伤害、不修改战斗数值。

喀秋莎追尾画面高度占比 40%；取消开炮乘员语音，0.6s 发射间隔不播报装填，70s 弹仓装填完成仅播报一次。每日签到海报以 cover 填满活动面板，界面文字与领取操作叠在背景上，四种横屏手机尺寸验证按钮可达。

新录音来自 Vehicle_Voice_Slices_EN_FIXED(1).zip。开场后，仅实际存活岗位按驾驶员、炮手、二炮手、无线电员播放；按用户指定将 Mechanic_Ready 作为无线电员录音，同岗位不会因两名装填手重复播报。四条就位语音均使用录音，完整录音可用时不调用 Android 合成语音。

移动语音由前进油门开启、加速跨越 25% 最高速度/增加油门、速度跨越最高速度的 98% 分别触发，每个触发独立 10% 概率。全速使用 98% 阈值以兼容指数加速永远无法数学上精确达到上限的物理实现。三种语音同级 FIFO，其他语音停止当前移动录音并清除待播放移动队列。

弹道修正只针对炮镜可用武器（坦克炮、机炮、女武神导弹），依据实际已飞行弹道选择 10m 内最近的已侦察敌车，按偏高、偏低、偏左、偏右播报，直接命中或造成爆炸伤害时不播报修正，冷却 10s。不读取未侦察敌人的位置来播报。
