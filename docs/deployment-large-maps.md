# 战斗部署、大地图与界面更新

突破无人区和黑暗森林使用2.5×2.5km丘陵交火、沙砾城墟；1v1保留2×2km。地形、碰撞边界、城市街区、树丛、缩圈、导航及小地图使用统一地图尺寸。突破无人区基地x=1250，z=100/2400；ABC前哨x=650/1250/1850，z=750/1750，两条战线仍相距1000m。重生区距基地前方200m。

菜单加入战斗先打开选车和地图，玩家可从当前队列选择首发。突破无人区被击毁后返回同一界面，15秒准备时间由引擎校验；可以提前选择车辆，时间结束后确认重生。原三次重生、损坏车辆不可重复使用规则保留。黑暗森林仍是淘汰赛，击毁后结算，不引入重生。

战斗标题删除；耐久、乘员和敌情缩为左边紧凑信息，雷达靠右上，提示移出中部，武器栏与开火按钮贴底。各车辆按实际模型边界拟合追尾相机，目标屏幕高度37.5%，检查范围35%—40%。炮镜红色敌情标识恢复。队友蓝色标识仅在双方通信范围（目前500m）内且位于屏幕内显示，出屏和在镜头后方时不生成边缘箭头。敌情标识继续遵守侦察数据。

队列编辑在一个界面完成四位置替换和移除；选择已在队列的载具会交换位置，保持唯一载具。最后一辆不能移除，编辑过程中不用重复开关弹窗。

提供的Ashes and Dawn Orchestral Remaster v3 MP3按原文件接入离线主菜单循环，进入对局暂停，回菜单继续；独立音乐音量控制，首次交互解锁浏览器音频。使用媒体流播放避免完整长音轨解码常驻内存。车辆、飞机及无人机引擎和爆炸播放增益增加15%；修复立体声事件绕过游戏音量总线的问题。
