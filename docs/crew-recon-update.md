# 乘员、遮蔽与战斗界面更新

本次只修改源码和资源，不生成 APK / H5 包。保留 `blindfire/index.html`、存档键 `bf-profile-v1` 与 v1/v2 存档兼容。

- 黑暗森林：玩家死亡立即显示个人结算并写入战币/研发点，不再等待全场决出胜者。死亡或已开始对局后的主动退出按本局结果/失败结算，重复退出不重复发奖。
- 丘陵生成随机分布的草丛（确定性地图布局，跨客户端一致），城墟不生成草丛。草丛中的载具侦查上限为 50m；任何实际开火使草丛隐藏失效 10 秒。车载、无人机、导弹、侦察机等侦查均检查建筑/树木/地形视线，已获情报按留存时间逐渐失效。空中飞行器不会借用地面草丛隐蔽。
- 新增六种乘员编组。每次有效受击以本次实际损失 HP / 最大 HP 为单个乘员损失概率，每次最多损失一人；免疫伤害不判定。炮长和驾驶员优先补位，每人同时占一个岗位。少于两人时车辆损失。车长和无线电员的侦查、情报惩罚相乘；车长冷却与二炮手主武器冷却惩罚相乘，并即时调整当前剩余冷却/装填。原本没有该岗位的载具不受该缺岗惩罚。维修仅恢复车体耐久，不复活乘员。毒圈不是炮击，不判定乘员伤亡。
- 转向（最大角速度 rad/s）：良 1.5，中 1.1，差 0.72。加速（速度响应系数 /s）：优 6，良 4.3，中 3，差 1.8。按用户给定每辆载具评级配置，最高/倒车速度不变。
- 匹配池包括同级、低一级、高一级；缺少的等级不会凭空生成车型。
- 切换武器/回到车辆保持原方向，并遵守装备自身的俯仰/发射架限制。炮镜瞄准改为逐帧提交、快速平滑视角，准星显示真实炮口方向；追尾包围盒缓存，避免拖动时反复遍历全模型。
- 三条科技树走线使用六辆车实际渲染缩略图，展示等级、研发点、拥有/研发状态。三四级空位保留；点击未拥有车型也可查看模型和数据。
- B 号清除重复车长塔圆柱和黑森峰图案材质；炮盾/20mm炮口套环随炮管俯仰，全部炮塔视镜随炮塔旋转，保留 22 轮与双履带。
- 附件 `bgm-71_tow.glb` 提取独立导弹，剔除展示发射器/剖面。按长度 1.17m、头朝 −Z 使用于悍驴和黑甲鱼。附件 `uav.glb` 作为新无人机，翼展 2m，保留贴图并压缩到 512px、Meshopt，绑定尾部螺旋桨。
- 音效从 Freesound / OpenGameArt 素材库获取，切片、单声道、均衡、音量归一化、循环边界淡化；15 个片段约 270KB。悍驴采用 Humvee 实录；其余按原型类别使用重型/二战/轻型发动机与炮声并分别调校音高、音量，未宣称全部为对应历史车型实录。素材授权/作者/原网址/切片范围/哈希见 `app/src/main/assets/audio/SOURCES.json`，游戏指南可查看版权信息。
