# 履带、炮镜与性能更新

本轮只提交源码，提交信息使用 `[skip ci]`，不触发 APK 工作流。

## 载具与武器

- B号坦克、跳虫：刚性履带片绕实际部件中心旋转，保留原顶点、UV、法线和贴图；左右履带分别使用实际行程。
- 黑甲鱼、战斗英雄号：根据底部履带 UV 与模型米制距离校准滚动方向和速度，沿主要纹理轴滚动，避免横向漂移。
- 四辆车使用履带底部及动画包络计算车底高度，按履带覆盖范围内的地形调整车体俯仰和侧倾，并覆盖道路高于地形13厘米的情况。
- 战斗英雄号：装填10秒，普通弹直接命中90伤害，爆炸半径5米，范围伤害按距离衰减；高爆弹仍为半径15米、中心95伤害。
- 黑甲鱼无人机侦察420米；载具自身侦察280米。
- 两辆坦克选择主炮后可打开2.5倍炮镜：炮镜按钮或V键开关，圆形瞄准镜与中心十字，镜头对齐实际炮口方向；开镜拖动灵敏度除以2.5，退出主炮或接管飞行器后关闭。

## 结构与性能

- `vehicle-grounding.js`：独立车辆接地，缓存静止车辆，复用计算向量和矩阵。
- `chase-camera.js`：独立追尾适配，仅模型朝向或瞄准角明显变化时重新遍历轮廓。
- `gun-sight.js`：独立炮镜适用条件和光学参数。
- `render-lines.js`：复用尾迹/弹道/毒圈GPU缓冲，容量不足时按倍数扩展。
- 不变的毒圈与弹道不重新计算；小地图以10Hz刷新，视角、瞄准和三维画面保持逐帧刷新。
- 重用敌情标记DOM节点、HUD节点和投影向量；取消侦察循环的临时传感器数组以及瞄准数据的JSON序列化复制。
- 履带接地包络使用预计算的初始路径点和复用输出，降低临时对象创建。

## 验证

- `node tests/renderer-air-support.test.mjs`：实际GLB加载、履带/轮子、坡地接地、炮镜光学倍率与炮口方向、开镜隐藏自身模型、退出恢复追尾、毒圈60帧不重建、线条120次更新复用缓冲、追尾适配缓存。
- `node tests/second-tier.test.cjs`：10秒装填、5米爆炸范围、高爆弹独立参数、420米无人机侦察边界、快照隔离与二级载具存档。
- `node tests/engine.test.js`：33项战斗规则。
- `node tests/dark-forest.test.cjs`：8车混战、三个难度完整对局、缩圈和最终胜者。
- 原有车库、科技树/旧存档迁移、测试货币、模型检查。

验证使用生产Three.js加载器和真实模型，但没有Android真机/WebGL驱动的视觉与帧率测量。因此本轮确认了缓冲复用和行为正确性，不能据此承诺某款手机的FPS。
